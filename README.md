# 齋藤拓也 / Takuya Saito

**フロントエンドエンジニア（業務委託）** — Next.js / React / TypeScript

エンジニア歴 8 年半、フロントエンド 5 年。業務委託として複数クライアントの新規開発・リニューアルに参加しています。フルリモートで、Slack を中心に BE / デザイナー / QA とチーム開発を行っています。

業務外でも個人開発を継続していて、企画から設計・実装・運用までを一人で担当しています。テストと CI による品質の作り込み、パフォーマンスとセキュリティの計測改善が得意です。
